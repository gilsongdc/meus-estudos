# Exercícios Próprios - Python

Nesta pasta estão exercícios desenvolvidos durante meus estudos para praticar e reforçar os conceitos aprendidos em Python.

## Exercícios

- `Cadastro_maioridade.py` — Programa que solicita nome, idade e cidade, valida a idade e informa a classificação do usuário.

- `CalculadoraIMC_testelivre.py` — Programa que solicita nome, peso e altura, calcula o IMC e permite realizar novos cálculos até o usuário digitar `sair`.

- `Tabuada_interativa.py` — Programa que solicita um número e exibe sua tabuada de 1 a 10 utilizando estruturas de repetição.

## Conceitos praticados

- Variáveis
- `input()`
- Conversão de tipos (`int` e `float`)
- Operadores matemáticos
- Estruturas condicionais (`if`, `elif` e `else`)
- Loop `while`
- Loop `for`
- `range()`
- `try/except`
- `break`
- Formatação de strings com `f-string`
