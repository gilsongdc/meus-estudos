
# Python Básico - Fundação Bradesco

Repositório com exemplos e exercícios desenvolvidos durante o curso **Linguagem de Programação Python - Básico**, oferecido pela Fundação Bradesco.

## Estrutura

- `01-apresentacao` — Introdução e primeiros contatos com Python.
- `02-variaveis-e-tipos` — Variáveis, tipos de dados, entrada e saída.
- `03-estruturas-logicas` — Estruturas de decisão e operadores lógicos.

## Objetivo

Registrar minha evolução nos estudos de Python e praticar os conceitos aprendidos durante o curso.
