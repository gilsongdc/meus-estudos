
# Módulo 4 — Estruturas Lógicas

Neste módulo foram estudadas estruturas de decisão e repetição na linguagem Python.

## Conteúdos estudados

- Operadores aritméticos
- Operadores relacionais
- Operadores lógicos
- Indentação
- Estrutura condicional `if`
- Estrutura condicional `if / else`
- Estrutura condicional `if / elif / else`
- Estrutura de repetição `for`
- Função `range()`
- Estrutura de repetição `while`

## Scripts desenvolvidos

- `operadores.py` — Exemplos de operadores relacionais e lógicos.
- `estruturassimples.py` — Exemplo de estrutura condicional e troca de valores entre variáveis.
- `mediavalores.py` — Programa que recebe valores positivos, calcula a soma, quantidade e média dos valores digitados.
